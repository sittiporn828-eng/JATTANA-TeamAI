# Source Evaluation Checklist

Use this before publishing a shared system-design reference.

- [ ] Upstream URL recorded
- [ ] Exact commit/tag recorded
- [ ] License/attribution checked
- [ ] Source type classified: notes, standard, code, or mixed
- [ ] Work-in-progress status recorded
- [ ] Topic count measured from the checkout
- [ ] Raw snapshot separated from local synthesis
- [ ] Real workspace projects mapped to topics
- [ ] Scope, scale, correctness, failure, security, and operations gates present
- [ ] High-consequence domains marked for official/compliance verification
- [ ] Existing workspace indexes and daily note updated
- [ ] No per-project duplication unless discoverability was tested and failed
